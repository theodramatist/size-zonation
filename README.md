# Size zonation explorer

Interactive descriptions of how worship, staffing and ministries vary with attendance and plate and pledge in the Episcopal Church Trajectory Study.

Website: https://theodramatist.github.io/size-zonation/

The standalone index.html includes its data, styles, fonts and calculations. No build step or external data service is required. The public tool retains its definitions and reading limits; private reports and research files are not included.

This edition supports automatic iframe height reporting for the Squarespace embed. No return button is included. The scientific tool is unchanged from the prepared public edition; the height helper only reports content height to its containing page.

GitHub Pages publishes the main branch root. The empty .nojekyll file bypasses Jekyll processing.
